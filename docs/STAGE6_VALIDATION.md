## 实现与证据约束

程序从明确选用、执行/提取/必需核验通过的当前结果生成表格，模型依据事实
占位符写八章中文论文。每项经验结论绑定确切结果 artifact ID/hash、规范化字段、
表格行与 CSV 行位置；解释章节沿同一结论清单关联证据，语义待研究者抽查。
资料年份、变量名和样本条件有来源；未经书目核实的正式引用保留为待补。
未执行的诊断、机制和差异检验只列局限。

生产循环与客户端预留一个实际写作调用，重试和两项审阅不能占用它。写作每次
只发送一次请求，失败或无预算产生部分材料。报告新版本不可覆盖，最后保存
发布清单；中断、选择变更、证据失效不能成为完整报告。COMPLETED 要求当前
有效完整论文且没有待答或在途操作。写作时间独立保存，恢复避免重置或重复扣除。

export 只读源会话，排除完整模型提示词/响应、秘密配置、输入保护/备份及历史
报告。逐次调用保留源 artifact ID/hash，事件保留设计、实验、尝试、请求、模型
与工具的关联。所有实质分析与技术尝试进入历史；参数拒绝保留在调用记录，
不伪造一次实际分析。坏文件逐项排除并标记部分交付，不能提供当前论文数字。

原输入/主体/提取文件保留原 hash，派生 Stata 入口另有 hash、来源与固定种子。
导出前后核对元数据和报告，再原子发布目录；缺少文件、环境/种子未知或硬编码
绝对路径时标记需适配，不声称可迁移。导出不能写入源 run 目录。
