# 阶段 2 验收记录

日期：2026-10-10。范围为开发计划「阶段 2 首个 Stata 执行闭环」。生产后端已经
接入固定 MCP 和阶段 1 状态契约；模型研究循环、真实人工修改、两项模型审阅
并发、完整研究 CLI 和论文导出仍属于后续阶段。固定开发验收不是自主研究演示。

## 已交付能力

- 数据检查、方法帮助和本机命令可用性查询；每项查询只有一个业务调用，内部
  MCP 生命周期及查询不重复计数。能力分别披露可用性、规范化范围和验证状态。
- 通用 do-file 执行、异步等待、主返回立即读取及完整归档；受控专用会话串行
  执行，锁覆盖运行、提取与归档。任何合法命令都可保存原始输出。
- 原始文件的独立备份、run 内不可变快照和每个 attempt 的工作副本。原件、
  备份和快照执行前后核验，不覆盖既有备份，不悄悄恢复被改写的用户文件。
- `tool_calls` 参数、attempt、实际主体和包装代码、服务/会话/task 身份、输出、
  日志、规范化结果及核验相互关联。新执行使用新尝试，重新提取只创建新结果。
- 统一中文错误，包括 Stata 错误码、连接、超时、取消、提取及完整性问题。
  未确认底层停止时记录 INTERRUPTED/UNKNOWN 并暂停，不能重新执行旧任务。
- `ivregress 2sls, small` 常规协方差规则：读取真实参数名，保留 double 精度，
  与 e(b)/e(V) 比较，并使用 Stata 实际 t 推断的 p 值和 95% 区间。

生产执行器只接收声明规格及代码，不读取原作者程序或独立参考数值。开发验收器
单独访问参考；数据、原件、许可、运行数据库及原始日志均保留在忽略目录。

限制，识别假设仍须按确认设计披露。

真实生命周期验收也通过：

| 案例 | 观察结果 |
| --- | --- |
| 缺失变量失败 | 实际 rc=111；保留失败代码、错误、原始返回与日志 |
| 修复后重试 | 同一规格新 attempt 和 tool call；operation 相同、retry_no 增加；旧产物保留 |

| 实际循环超时 | CPU 循环已写入开始标记；8 秒预算后取消并确认专用工作进程退出 |
| 实际循环取消 | 确认开始后发送取消，停止专用会话并核对 PID 退出，结果不能选入结论 |
| 取消后新会话 | 使用新 session 和新 attempt，真实 summarize 成功 |
| 关闭恢复 | 两项当前 IV 结果仍可读取；无异常文件或遗留运行任务 |
| 数据完整性 | 原始数据 SHA256 未变，备份及快照保留 |

数据库共记录 10 次业务工具调用、1 次技术重试、0 次模型请求；MCP 轮询单列在
所属调用的诊断 trace 内。没有在途调用。未知 token 用量保持空值，未伪造费用。

联调发现 Stata 的 postfile 类型声明只作用于其紧随字段，已为每个推断字段显式
指定 double；严格矩阵一致性检查曾拒绝 float 精度输出，未放宽容差来制造通过。
主体与提取脚本也是核验证据，改变它们会使选中结果读取失败。

## 接口及格式说明

AnalysisBackend 的执行方法现在明确接收 `StataProgram` 并返回 AnalysisOutcome，
其结果字段仍使用同一 ExperimentResult。调用方可按统一错误反馈修复代码，
不能把未执行或未提取输出当作成功数字。研究循环尚未发布，此接口修订没有
已发布 CLI 使用者；完整 CLI 仍只开放 doctor 和版本查询。

能力结构增加可选规范化字段，旧记录按 unknown 读取。数据库仍为九表 v1，
应用版本仍为 0.1.0；没有编造数据迁移或重建旧库。停止确认入口要求调用者先
取得旧进程退出证据，保存确认事件而不把未知返回改记为成功。备份与路径检查
不能阻止任意本机代码访问当前用户权限下的文件，不称为完整沙箱。
