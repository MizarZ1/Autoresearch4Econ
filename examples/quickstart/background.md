# 工程演示背景

这是项目自行生成的合成数据。目的是检查安装、研究设计确认、Stata 执行、结果读取、补充分析、审阅、论文与可迁移复现包。任务有预先规定的工程验收范围，不能据此证明 Agent 能独立完成任意科学研究。

研究者应检查模型提出的样本、变量角色和方法。在确认前可以要求修改、拒绝或暂停。不要为获得显著性改变样本。演示允许在同一已确认设计中运行 ylinear 对 x 的含截距 OLS，以及 x 的单变量描述统计。常规标准误用于演示，数值结果不能支持现实因果判断。

脚本固定设计验收与真实模型闭环是两类验证；如果用脚本自动接受设计，必须标注为脚本化确认。独立研究者审阅仍需由真实研究者完成。
